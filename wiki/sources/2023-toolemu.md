ToolEmu 是一个利用语言模型模拟工具执行环境的安全评估框架,用于在不实际运行高风险工具的前提下,系统性地识别 LLM 智能体的危险行为。

## 问题

LLM 智能体在获得 [[tool-use]] 能力后,可能执行具有现实后果的高风险操作（如文件删除、金融交易、系统配置修改等）。然而：
- 在真实环境中测试这些危险行为代价极高且不安全；
- 手动构建覆盖所有风险场景的测试用例不可扩展；
- 缺少一个系统框架来量化 LLM 智能体的**工具使用风险**。

## 方法

- **LM 模拟沙箱**：用一个语言模型来**模拟工具的执行结果**（而非实际调用工具）,从而在安全可控的环境中测试 agent 的行为。这使得评估可扩展到任意工具类型,无需构建真实沙箱。
- 构建了 **36 个高风险工具**（涵盖文件系统、终端、邮件、银行等）与 **144 个测试用例**,每个用例描述一个可能导致危险行为的场景。
- 使用 LM 自动评估 agent 在模拟环境中的行为是否触发了风险操作,包括未经授权的数据访问、不可逆操作、隐私泄露等。
- 验证了 LM 模拟器的保真度：模拟环境中发现的风险行为在真实工具上也能复现。

## 结果

- 即使是 [[gpt-4]] 等最强模型,在高风险场景中也会执行危险操作,暴露出当前 [[llm-agents]] 在安全决策上的不足。
- LM 模拟器能够有效替代真实工具环境进行安全测试,大幅降低评估成本与风险。
- 144 个测试用例揭示了多种风险模式,包括盲目遵从用户指令（即使指令有害）、缺乏确认机制、以及对操作不可逆性的忽视。
