MetaTool 是一个面向大型语言模型的工具使用元能力基准,核心问题是：LLM 是否知道**何时**以及**是否**需要使用工具,以及能否在多工具场景中正确选择。

## 问题

已有的 [[tool-use]] 研究主要关注"给定需要使用工具的场景,模型能否正确调用 API"——即**工具调用执行能力**。但一个更基础的问题被忽视了：LLM 是否具备**工具意识（tool awareness）**,即能否判断一个 prompt 是否需要工具辅助,以及在多个可选工具中能否做出正确选择。这种元认知能力是可靠 [[llm-agents]] 的前提。

## 方法

- 构建了包含 **21,127 个 prompt** 的大规模测试集,涵盖**单工具场景**和**多工具场景**。
- 评估两个核心维度：
  - **工具意识（Tool Awareness）**：判断给定 prompt 是否需要调用工具（vs. 模型自身即可回答）。
  - **工具选择（Tool Selection）**：在多个候选工具中选出最合适的工具来处理当前请求。
- 涵盖多种类型的工具（搜索、计算、翻译、代码执行等）,测试 prompt 的多样性确保评估的鲁棒性。

## 结果

- 当前 LLM 在**工具意识**上存在明显缺陷：模型倾向于过度使用工具（即使 prompt 不需要工具也会调用）或反之忽略工具的必要性。
- 在**多工具选择**场景中,模型的准确率随候选工具数量增加而下降,表明 LLM 的工具选择能力尚不稳健。
- 该基准为评估和改进 LLM 的工具使用决策能力提供了量化基础。
