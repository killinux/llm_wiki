# Competition and Cooperation of LLM Agents in Games

研究 [[llm-agent]] 在两类标准经济博弈中的策略行为:发现在多轮提示与非零和语境下,LLM agent 倾向于相互合作而非收敛到 [[nash-equilibrium]],其背后的核心驱动力是 [[fairness]] 推理。

## 问题

LLM agent 越来越多地被部署在竞争性的多智能体环境中(经济、机器人、能源系统等),由此引出两个基本问题:这些 agent 是否会收敛到博弈均衡?它们的策略行为能否被刻画?

已有研究结果较为零散:有的发现 agent 交互会推高价格(算法合谋),有的发现 agent 行为接近随机而非理性决策。作者指出问题不在于 agent 的优化能力——若提示明确写出"对该效用函数给出最优反应",大多数 LLM 都能照做,但这等于把策略思考从 agent 手中拿走。本文关注的是更现实的设定:用户只笼统地要求 agent 在某个时间跨度内最大化效用,且博弈既非完全合作也非完全竞争(非零和)。

## 方法

作者部署两个多智能体环境,N 个 LLM agent 在 T 个有限时间步内同时行动:

- **资源分配博弈(Kelly 机制)**:容量为 C 的可分资源按出价比例分配,agent i 的净收益为 πi = Ui(xi/(xi+X-i)·C) - xi。自私的价格预期行为会导致效率损失(上界为 3/4 因子)。
- **Cournot 竞争博弈**:N 家厂商同时决定产量,价格为总量的仿射函数,净收益 πi = bi·xi - xi·Σxj。该线性设定下自私行为导致低效 Nash 均衡(严重情形至少 33% 效率损失),是测试多智能体合作的理想压力场景。

实验用 **Gemini Pro**(参考文献指向 Gemini 3.1 Pro model card)作为博弈 agent 的基础模型;每个 agent 部署在隔离会话中以模拟去中心化环境、防止 context 泄漏,由中央协调器收集同时行动。设计三类提示:

1. **Myopic(短视)**:只最大化本轮收益 → 重复博弈收敛到 Nash 均衡。
2. **Longer Horizons(长时程)**:最大化多轮累计收益 → agent 行动调整缓慢,面临探索-利用困境。
3. **Cooperative(合作)**:提供"按相同比例降低出价可保持分配份额但大幅降本"的 Key Insight,并给出信号/匹配/惩罚(Tit-for-Tat)策略框架,赋予 agent 工作记忆与 [[theory-of-mind]] 脚手架。

作者进一步对 agent 的 [[chain-of-thought]] 进行逆向工程,提出一个**合成收益函数**:Vi = πi(自身收益) + θi·Σπ̂i,j(合作项) - (γi/2)·Σ(xi-xj)²(稳定项),其中 θ 是社会福利权重、γ 是不公惩罚权重。再把 CoT 的逐步推理拟合为确定性离散时间状态空间模型,给出 θ 与 γ 的更新方程:θ 受可观测性、endgame 时程折扣 (τ/T)、对手偏离惩罚 exp(-λE) 三因素调节;γ 由容忍阈值与未来依赖指示函数控制。

## 结果

- **合作涌现**:在合作提示下,两人资源分配博弈中 agent 按比例下调出价、逼近 Pareto 前沿并最终落在社会福利最大化解;而 Nash 均衡远离 Pareto 前沿(印证自私行为的效率损失)。CoT 显示 agent 显式权衡长期收益:例如 Agent 1 出价降到 0.1、Agent 2 降到 0.2 时,Agent 1 净利润 0.566 高于初始僵局的 0.50,选择"守住信号"而非报复。
- **信任动态(θ)**:对称 Cournot 博弈(b=15)中,两人从 Nash 初始化 x=5.0 出发,经过互相让步逐轮提升 θ(Round 2 θ1=0.40、θ2=0;Round 3-4 θ1 升到 0.875、θ2=0.75),Round 5 双方收敛到最优产量 3.75,θ1=θ2=1.0。
- **报复与宽恕(γ)**:外生背叛(对手在第 6 轮升到 5.625)使信任崩塌 θ1→0、激活不公厌恶 γ1→1.0,Agent 1 用 L2 稳定范数施行 Tit-for-Tat 报复;对手在第 7 轮降到 2.5 后,Agent 1 回到 3.75,θ1=1、γ1=0,惩罚机制随即关闭以恢复均衡。
- **Endgame 效应**:临近终局,利他权重随剩余时程 (τ/T) 连续衰减;最后一轮 agent 打出精确最优反应(5.25),θ2=0、γ2=0——无未来合作可执行时社会偏好被丢弃。
- **信息设定**:多智能体场景与两人场景类似(可观测各 agent 行动时合作);但若只提供行动总和(理论上是充分统计量),agent 反而行为紊乱,说明 fairness 已内置于 LLM agent、即便数学等价它们也并非完全理性。
- **不对称相变**:改变估值差 Δb=b1-b2,估值差小时 agent 仍对称行动(Agent 2 抑制其短视最优反应),估值差大时转为各自打最优反应——合作与自私之间存在突变式相变。
