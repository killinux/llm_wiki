# Fogg Behavior Model

Fogg Behavior Model(福格行为模型)由 BJ Fogg 提出,主张行为(Behavior)在动机(Motivation)、能力(Ability)与提示(Prompt/Trigger)三者同时具备时才会发生,即 B = MAP。
