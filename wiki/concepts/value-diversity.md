# value diversity

价值多样性(value diversity)指在多智能体系统中,为不同的 LLM 智能体注入相互区别的价值取向(如基于 Schwartz 价值观体系),使群体在价值层面呈现异质性,从而影响集体行为的稳定性、涌现与规则形成。

## 在本 wiki 中的出现

- [[2025-multi-agent-llm-value-diversity]]:通过 Schwartz 价值观给 LLM 智能体注入价值多样性的多智能体社会模拟,发现价值多样性提升集体行为的价值稳定性、涌现与自发规则创造,但极端异质带来边际递减与不稳定。
