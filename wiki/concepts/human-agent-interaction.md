# Human-agent interaction

人-agent 交互(Human-agent interaction)指人类与基于 LLM 的智能体之间的协作、沟通与相互影响,是研究 agent 在与人共处场景下如何行为、适应并保持负责任表现的一类问题。

## 在本 wiki 中的出现

- [[2025-ai-agent-behavioral-science]]:立场/综述论文,提出 AI Agent Behavioral Science 范式,把 LLM agent 当作行为实体,通过系统观察、干预与理论解释来研究其行为、适应与 responsible AI;人-agent 交互是其三类核心场景之一(个体、多 agent、人-agent 交互)。
