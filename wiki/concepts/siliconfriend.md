# SiliconFriend

SiliconFriend 是一类面向长期对话与记忆增强的 LLM 友伴式 agent,强调通过记忆机制与自进化框架持续优化交互质量。

## 在本 wiki 中的出现

- [[2024-sage-self-evolving-agents]]:由 User/Assistant/Checker 三 agent 组成、结合迭代反馈、反思与基于 Ebbinghaus 遗忘曲线的记忆优化的自进化 LLM agent 框架,对小模型提升尤为显著。
