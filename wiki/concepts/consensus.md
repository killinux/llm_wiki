# Consensus

Consensus 指多个 agent(或节点)在去中心化、可能受限的通信条件下,就某个共同决策或状态达成一致的过程,是分布式计算中的经典问题之一。

## 在本 wiki 中的出现

- [[2025-agentsnet-multi-agent-reasoning]]:AGENTSNET 将 consensus 作为借鉴自分布式计算的五个经典问题之一(与 coloring、vertex cover、matching、leader election 并列),用于衡量多 agent LLM 网络在给定通信拓扑下的自组织、去中心化通信与协作推理能力,实验最多探测 100 个 agent。
