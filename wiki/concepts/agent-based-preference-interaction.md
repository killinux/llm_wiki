# Agent-based preference interaction

基于 agent 的偏好交互,指让用户、物品乃至平台等多方各自由 LLM agent 表征,通过 agent 之间的主动交互(如物品自我推销、平台重排)来表达与协调偏好,从而完成推荐或匹配的范式。

## 在本 wiki 中的出现

- [[2026-trirec-tri-party-agent-recommendation]]:TriRec 是首个用户—物品—平台 tri-party LLM-agent 推荐框架,让物品 agent 主动个性化自我推销,再由平台做曝光感知的多目标重排,在精度、公平与物品效用上同时提升。
