# Cooperation

合作(Cooperation)指多个智能体在存在个体利益与集体利益冲突的情境(如社会困境)中,选择相互配合而非相互背叛,以达成更优集体结果的行为。

## 在本 wiki 中的出现

- [[2025-llm-agents-cooperate-social-dilemma]]:让 ChatGPT-4o 与 Claude 3.5 Sonnet 为 iterated Prisoner's Dilemma 写出完整策略(而非逐步出招),并用 evolutionary game theory / Moran process 模拟 LLM agent 群体演化。发现多数场景下侵略策略处于劣势、系统倾向合作,但博弈论 prompt 与 self-refine 会增强侵略策略并提高收敛到侵略均衡的风险。
- [[2026-llm-agents-competition-cooperation-games]]:研究 LLM agent 在资源分配博弈与 Cournot 竞争中的策略行为:多轮非零和提示下 agent 倾向合作而非收敛到 Nash 均衡,fairness 推理是核心驱动,并提出 θ/γ 合成收益函数框架刻画其信任建立、报复与 endgame 衰减动态。
