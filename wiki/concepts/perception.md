# 感知模块

感知模块是 LLM agent 中负责接收并解释外部环境信息(如推荐结果、交互上下文)的组件,为后续的记忆与决策提供输入。

## 在本 wiki 中的出现

- [[2025-simuser-llm-user-simulation-recsys]]:基于 LLM 的 agent 框架,用从历史数据推断的 persona、记忆、感知与决策模块构建可信合成用户来低成本评估推荐系统。
