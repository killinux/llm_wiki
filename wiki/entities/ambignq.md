# AmbigNQ

AmbigNQ 是一个开放域问答 (open-domain QA) 数据集/基准,聚焦于自然问题中的歧义 (ambiguity),要求模型识别问题的多种可能解读并给出相应的多个答案。

## 在本 wiki 中的出现

- [[2023-critic]]:CRITIC 让 LLM 通过与搜索引擎、代码解释器、PERSPECTIVE API 等外部工具交互来自我验证并迭代修正输出,证明外部反馈对自我改进至关重要;AmbigNQ 在其中作为问答任务的评测基准之一。
