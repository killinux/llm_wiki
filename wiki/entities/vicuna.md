# Vicuna

Vicuna 是一个基于 LLaMA、通过用户对话数据进行指令微调得到的开源对话大语言模型。

## 在本 wiki 中的出现

- [[2023-multi-agent-debate]]:作为参与辩论的 LLM 智能体之一,被纳入 Multi-Agent Debate(MAD)框架中。MAD 让多个 LLM 智能体"针锋相对"地辩论,并由裁判进行仲裁,以缓解自我反思中的 Degeneration-of-Thought 问题并激发发散性思维。
- [[2023-agenttuning]]:通过构建跨任务 agent 交互轨迹数据集 AgentInstruct 并与通用指令混合微调,使开源 Llama 2 获得可泛化的 agent 能力且不损害通用能力。
