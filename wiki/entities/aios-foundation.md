# AIOS Foundation

AIOS Foundation 是一个聚焦于 LLM agent 操作系统与底层基础设施(包括记忆、调度与工具集成)的研究组织。

## 在本 wiki 中的出现

- [[2025-agentic-memory-llm-agents]]:受 Zettelkasten 启发的 agentic 记忆系统,通过结构化笔记、自主链接生成与记忆演化为 LLM agent 提供可持续演化的长期记忆。
