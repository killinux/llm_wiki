# TabMWP

TabMWP (Tabular Math Word Problems) 是一个面向表格数学应用题的推理评测基准,要求模型基于结构化表格数据进行多步数值与逻辑推理来作答。

## 在本 wiki 中的出现

- 在 [[2023-critic]] 中,TabMWP 被用作评测基准之一:CRITIC 让 LLM 通过与搜索引擎、代码解释器、PERSPECTIVE API 等外部工具交互来自我验证并迭代修正输出,在该类推理任务上验证外部反馈对自我改进的作用。
