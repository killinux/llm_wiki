# Llama 3

Llama 3 是 Meta 发布的开放权重大语言模型系列,常被用作研究中可微调的基座模型(含 7B 级规模档位)。

## 在本 wiki 中的出现

- [[2024-recursive-introspection-rise]]:RISE 将单轮问题建模为多轮 MDP 并用 reward-weighted regression 迭代微调,让 7B 级 LLM 在无外部反馈下学会跨多轮递归反思并修正答案。
