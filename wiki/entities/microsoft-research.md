# Microsoft Research

Microsoft Research 是 Microsoft 旗下的研究机构,从事计算机科学及相关领域的基础与应用研究。

## 在本 wiki 中的出现

- [[2023-autogen]]:提出方。Microsoft Research 提出了开源多 agent 框架 AutoGen,通过可定制、可对话的 agent 之间的会话编程来构建复杂的 LLM 应用。
- [[2024-v-star-verifiers-for-self-taught-reasoners]]:V-STaR 在自我提升迭代中复用正确与错误的模型生成解,用 DPO 训练 verifier 在测试时对候选解排序,使 LLaMA2 在数学推理上绝对提升 6%~17%、代码生成 4%~12%。
- [[2024-generative-ai-as-economic-agents]]:立场/理论论文,主张把生成式 AI 本身建模为有独立信息与(可能错位的)偏好的经济主体,并给出一个把 AI agent 嵌入博弈的形式化框架。
