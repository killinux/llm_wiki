# AI User Agent

AI User 是 CAMEL 角色扮演框架中负责下达指令、扮演"用户/任务发起方"角色的 LLM 智能体,与 AI Assistant 配对协作以在最少人工干预下完成任务。

## 在本 wiki 中的出现

- [[2023-camel-communicative-agents]]:CAMEL 通过角色扮演(role-playing)与 inception prompting,让两个 LLM 智能体——AI User 与 AI Assistant——自主对话协作。其中 AI User 充当指令发出者,引导 AI Assistant 完成具体任务;二者在最少人工干预下持续交互,从而自动生成大规模的指令/对话数据。
