# ToolLLM

ToolLLM 是一个基于 16,000+ 真实 REST API（来自 RapidAPI）的工具使用训练与评估框架。它同时提供数据构建流水线（ToolBench 数据集）和评估协议，用于训练和衡量 LLM 在大规模真实 API 场景下的工具调用能力。
