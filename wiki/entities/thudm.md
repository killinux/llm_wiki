# THUDM

THUDM (Tsinghua University Data Mining group) 是清华大学的研究团队，专注于大语言模型与 LLM Agent 等方向的研究。

## 在本 wiki 中的出现

- [[2023-agentbench]]：THUDM 是该工作的主要研究团队。AgentBench 是首个系统评估 LLM-as-Agent 能力的多维基准，横跨 8 个交互环境测评 29 个模型，揭示了商业模型与开源模型在 Agent 能力上的巨大差距。
