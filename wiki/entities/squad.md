# SQuAD 2.0

SQuAD 2.0(Stanford Question Answering Dataset 2.0)是斯坦福大学发布的阅读理解基准,在原始 SQuAD 的基础上加入了不可回答问题,要求模型在给定段落无法支撑答案时做出"无法回答"的判断。

## 在本 wiki 中的出现

- [[2026-orgagent-company-style-mas]]:提出公司式层级多智能体框架 OrgAgent(治理/执行/合规三层),实证表明层级组织在多数推理任务上同时提升效果并大幅降低 token 成本。
