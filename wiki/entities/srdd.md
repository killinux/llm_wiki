# SRDD

SRDD (Software Requirement Description Dataset) 是用于评估端到端软件开发能力的需求描述数据集,包含多条软件需求任务,供智能体根据需求生成完整软件。

## 在本 wiki 中的出现

- 在 [[2023-chatdev]] 中,SRDD 作为评测基准:ChatDev 用多个 LLM 驱动的角色化软件智能体,通过对话链沿瀑布式流程协作完成设计、编码、测试、文档的完整软件开发,并以 SRDD 中的需求作为输入任务来检验其端到端软件生成效果。
