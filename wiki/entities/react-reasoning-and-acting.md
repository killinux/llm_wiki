# ReAct

ReAct (Reasoning and Acting) 是一种让 LLM 在解决任务时交替生成推理轨迹 (reasoning traces) 与行动 (actions) 的范式,使模型能够边思考边与外部环境交互。

## 在本 wiki 中的出现

- [[2023-expel]]:以 ReAct 风格的 LLM Agent 为基础。ExpeL 在不更新模型参数的前提下,让 Agent 从跨任务经验中自主抽取自然语言洞见,并召回相似的成功轨迹,以提升其在决策任务上的表现。
