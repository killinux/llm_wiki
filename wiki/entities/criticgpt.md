# CriticGPT

CriticGPT 是 OpenAI 基于 GPT-4 级别模型、用 RLHF 训练的 critic(评论者)模型,通过让 LLM 写自然语言批评来指出代码中的 bug,以可扩展监督的方式帮助人类更准确地评估模型生成的代码。
