# AgentBoard

AgentBoard 是一个面向多轮 LLM agent 的分析式评估面板，被选为 NeurIPS 2024 Oral。它不仅提供最终成功率，还通过进度率（progress rate）等细粒度指标揭示 agent 的中间行为与瓶颈。
