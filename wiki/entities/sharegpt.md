# ShareGPT

ShareGPT 是一个由用户分享的真实人机对话数据集,常用于大语言模型的指令微调与对话能力训练。

## 在本 wiki 中的出现

- [[2023-agenttuning]]:通过构建跨任务 agent 交互轨迹数据集 AgentInstruct 并与通用指令混合微调,使开源 Llama 2 获得可泛化的 agent 能力且不损害通用能力(ShareGPT 作为其通用指令数据来源之一)。
