# AI Assistant Agent

由 LLM 驱动、扮演"助手"角色的智能体,在角色扮演框架中接收任务指令并执行,以完成既定目标。

## 在本 wiki 中的出现
- [[2024-generative-ai-as-economic-agents]]:立场/理论论文,主张把生成式 AI 本身建模为有独立信息与(可能错位的)偏好的经济主体,并给出一个把 AI agent 嵌入博弈的形式化框架。
- [[2025-memory-os-of-ai-agent]]:借鉴操作系统内存管理,为 AI agent 设计分层(STM/MTM/LPM)、heat 驱动更新的 MemoryOS,统一 Storage/Updating/Retrieval/Generation 四模块,在 LoCoMo 上 F1 平均提升 49.11%、BLEU-1 提升 46.18%。

- [[2023-camel-communicative-agents]]:在 CAMEL 框架中,AI Assistant 是两个协作智能体之一,与 AI User 配对。CAMEL 通过角色扮演(role-playing)与 inception prompting,让 AI User 负责下达/拆解任务指令,AI Assistant 负责响应并执行,二者在最少人工干预下自主对话协作完成任务,并自动生成大规模的指令/对话数据。
