# AgentTorch

AgentTorch 是一个大规模 agent-based modeling(ABM)框架,通过引入 LLM 行为来增强百万级仿真中的个体自适应能力。

## 在本 wiki 中的出现

- [[2024-limits-of-agency-in-agent-based-models]]:提出 LLM archetypes——为少数代表性 agent 类型查询 LLM 行为,再概率采样到个体,从而在百万级 ABM 仿真(NYC 840 万人 COVID-19)中保持规模的同时引入 LLM 自适应行为。
