# Claude 3.7 Sonnet

Claude 3.7 Sonnet 是 Anthropic 推出的一款大语言模型,常被用作 agent 任务与推理基准中的受测后端模型。

## 在本 wiki 中的出现

- [[2025-agentsnet-multi-agent-reasoning]]:在 AGENTSNET 多 agent 基准(借鉴分布式计算的 coloring、vertex cover、matching、leader election、consensus 五个经典问题,最多探测 100 个 agent)中作为受测模型,衡量其在给定通信拓扑下的自组织、去中心化通信与协作推理能力。
